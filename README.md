# БЛИК, плоская версия

Все файлы лежат рядом, без вложенных папок. `index.html` ищет фотографии
в той же папке, где лежит сам: `work-01.jpg`, а не `img/work-01.jpg`.

Именно такая раскладка сейчас на https://blik-omega.vercel.app

## Что загружать

Выделить все файлы в этой папке и перетащить в репозиторий. Одинаковые имена
перезапишутся, недостающие добавятся.

## Если фото не открываются

Откройте адрес сайта и допишите в конце имя файла:

- открылось `сайт/work-01.jpg` → раскладка плоская, нужен `index.html` из этой папки
- открылось `сайт/img/work-01.jpg` → раскладка с папкой, нужен `index.html` из `blik-site`

Смешивать нельзя: страница из одной версии не найдёт фотографии из другой.

## Остальное

Как добавлять работы, менять контакты и прайс, расписано в `blik-site/README.md`.
Отличие только в том, что здесь в поле `src` пишется имя файла без `img/`.


## Раскладка файлов больше не важна

Приложение ищет фотографию сначала рядом с `index.html`, потом в папке `img`.
Если не нашло ни там, ни там, плитка просто убирается, дыры в галерее не будет.
Так что перепутать версии уже нельзя.
