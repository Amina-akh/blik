# БЛИК

Веб-приложение для клиентов колориста. Открывается по ссылке в шапке профиля
в Инстаграме, без установки. Всё считается в браузере, сервер не нужен.

## Что где

```
index.html          код приложения, 61 КБ
img/work-01..22     работы мастера
img/before-after-01..04  коллажи «до и после»
```

Каждый файл меньше 140 КБ, поэтому GitHub показывает их все.

## Как выложить на GitHub Pages

1. Создайте репозиторий, например `blik`.
2. Загрузите в него `index.html` и папку `img` целиком.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
4. Через минуту сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/blik/`.
5. Эту ссылку и ставьте в шапку профиля.

Загружать через веб-интерфейс: Add file → Upload files, перетащить `index.html`
и папку `img`. Через `git`:

```
git init
git add .
git commit -m "БЛИК"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/blik.git
git push -u origin main
```

## Как заменить или добавить работы

1. Положите новый файл в `img/`. Размер по длинной стороне около 900 пикселей,
   JPEG качества 75. Больше не нужно, телефон разницы не покажет, а страница
   станет тяжелее.
2. В `index.html` в начале тега `<script>` найдите массив `WORKS` и допишите
   `{"src":"img/work-23.jpg","cap":"Подпись"}`.
3. Коллажи «до и после» лежат в массиве `BEFORE_AFTER` рядом.

Первая работа в списке становится обложкой на экране «Запись».

## Контакты мастера

Ниже массивов, в объекте `MASTER`:

```js
var MASTER = { city:"Москва", telegram:"Oll_unique", whatsapp:"", ... };
```

- `telegram` — ник без собаки. Кнопка копирует карточку клиента в буфер
  и открывает чат, человеку остаётся вставить её сообщением.
- `whatsapp` — только цифры, например `79990001122`. Если пусто, кнопка не показывается.
- `headline`, `about`, `review`, `reviewWho` — тексты на экране «Запись».

## Цены

В объекте `TECH`. Сейчас стоит вилка по рынку Москвы на длину до лопаток,
за один сеанс. Замените на реальный прайс мастера.

| Техника | От | До |
|---|---|---|
| Тонирование | 4 000 | 7 000 |
| Окрашивание в один тон | 6 000 | 9 000 |
| Корни и тонирование | 9 000 | 14 000 |
| Шатуш или балаяж | 13 000 | 20 000 |
| Осветление в блонд | 15 000 | 25 000 |

Итог умножается на число сеансов.

## Как устроен расчёт

- **Запас осветления за сеанс**: хна = 1 уровень, низкая пористость = 4,
  средняя = 3, высокая = 2.
- **Число сеансов** = разница уровней делить на запас, округление вверх.
- **Пауза между сеансами**: 6 недель при высокой пористости, иначе 4.
- **Сколько держится тон**: база 6 недель, минус 3 при высокой пористости,
  минус 1 при средней, минус 1 если осветление больше трёх уровней.
- **Цикл цвета**: дни из `PLAN` умножаются на 0.8 при высокой пористости
  и на 1.15 при низкой. Кнопка записи появляется за 10 дней до финальной точки.

## Дизайн

Шрифты Prata и Onest с Google Fonts, обе с кириллицей. Фон почти чёрный,
акцент взят с 9 уровня шкалы тонов. Насыщенный цвет в интерфейсе принадлежит
только волосам: свотчам уровней и палитре оттенков. Светлая и тёмная темы
переключаются вместе с системной.
